# 雲居の文庫（くもゐのふみぐら）

著作権の保護期間が満了した刊本から起こした日本の古典を、作品ごとのリポジトリに置いています。誰でも読み・使い・直せます（CC0 1.0）。

**サイトで読む：[雲居の文庫（くもゐのふみぐら）](https://informanellica.com/kumoi-no-fumigura/)**

「雲居」は和歌によく詠まれる言葉で、空のはるか高い所と宮中の両方をさします。「ふみぐら」は書物の蔵のことです。
