# 雲居の文庫（くもゐのふみぐら）

著作権の保護期間が満了した刊本から起こした日本の古典を、作品ごとのリポジトリに置いています。誰でも読み・使い・直せます（CC0 1.0）。

「雲居」は和歌によく詠まれる言葉で、空のはるか高い所と宮中の両方をさします。「ふみぐら」は書物の蔵のことです。

## 作品

**物語**：[伊勢物語](https://github.com/kumoi-no-fumigura/ise-monogatari)（いせものがたり）

**日記**：[土佐日記](https://github.com/kumoi-no-fumigura/tosa-nikki)（とさにっき）

**軍記**：[太平記](https://github.com/kumoi-no-fumigura/taiheiki)（たいへいき）

## 本文について

本文は、国立国会図書館デジタルコレクションのインターネット公開資料（保護期間満了）の全文テキスト（OCR）です。いま公開している本文は、作品の範囲の切り出しと段落分けのほかは手を加えておらず、誤りを含みます。誤りを見つけたら、各作品のリポジトリの Issue か Pull Request で知らせてください。

## AI の利用について

このプロジェクトでは、作品の説明・作中歌の抽出・読みがな・現代語訳・解説などを作るときに AI を使うことがあります。人が確かめたものも含め、個々の記述には印を付けていません。誤りに気づいたら Issue で知らせてください。
